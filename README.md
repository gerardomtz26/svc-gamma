# svc-gamma

A manifest and a script for a media service. **No content is hosted here** — the script only
talks to third-party endpoints at run time; nothing is stored or redistributed.

- `source.json` — install this file's raw URL in the app (Services → **+**).
- `source.js` — the script the app runs.
- `icon.png` — the icon the manifest points at.
